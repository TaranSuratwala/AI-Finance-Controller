# 🛡️ AI Finance Controller
**Razorpay Buildathon 2026 Submission**

The **AI Finance Controller** is an enterprise-grade, deterministic AI reconciliation engine designed for modern payment gateways. It safely bridges the gap between unstructured financial data (like messy webhook descriptions) and strict, mathematically sound ledger systems.

## 🚀 The Problem
B2B payments are messy. A single ₹1,000 settlement might be paying off two different invoices, but the gateway fee was deducted, and the webhook payload only contains a messy memo string like *"payment for INV-100 and INV-101"*. 
Traditional regex parsers fail at complex B2B batching, and standard LLMs hallucinate math, introducing catastrophic financial risk (False Positives).

## 💡 Our Solution
We built an **Independent Auditor AI** paired with a **Deterministic Gatekeeper**. 
1. **The AI** extracts the raw invoice totals from messy text and acts as an auditor, independently calculating what the net gateway fee *should* have been.
2. **The Gatekeeper** strictly enforces idempotency and blocks the transaction if the AI's audited net amount doesn't perfectly match the actual webhook payload down to the decimal.

### 📊 Proof of Work: 100% Accuracy on Adversarial Data
Tested against 100+ synthetic and real-world GitHub datasets, the system handles extreme chaos:
*   ✅ **Amount Mismatches:** Detects when a payload is off by just 50 paise.
*   ✅ **Missing Fees:** Catches when the gateway forgets to deduct a 2% fee.
*   ✅ **Batched Settlements:** AI successfully splits a single payment across multiple invoices.
*   ✅ **Stale State:** Rejects payments for invoices that are already closed in the ERP.
*   ✅ **Duplicate Webhooks:** Strict idempotency checks prevent double-crediting.

**Result: 0% False Positives.** It never allows a mismatched transaction to pass.

## 🏗️ Architecture & Features

- **FastAPI Production Webhook Server:** A live `/webhook/razorpay` endpoint that validates `X-Razorpay-Signature` HMAC SHA256 security.
- **Asynchronous Processing:** Uses `BackgroundTasks` to instantly return `200 OK` to Razorpay while the AI reconciles in the background.
- **Immutable SQLite Audit Ledger:** Every rejected transaction is securely logged into an audit database for the FinOps team.
- **Merchant Support Portal:** A Streamlit dashboard that translates technical errors (like `AMOUNT_MISMATCH`) into friendly, human-readable explanations generated by the AI's internal reasoning.
- **Dockerized:** 1-click deployment using `docker-compose`.

## 🛠️ Tech Stack
- **AI/LLM:** Gemini 3.6 Flash (via `instructor` for strict Pydantic JSON schemas)
- **Backend:** FastAPI, Python, SQLite, Asyncio
- **Frontend/Dashboards:** Streamlit, Altair Charts, Pandas
- **DevOps:** Docker, Docker Compose

## 💻 Quickstart (How to Run)

### Option 1: Docker (Recommended)
You can spin up the entire architecture (FastAPI Backend + Streamlit UI) with one command:
```bash
docker-compose up --build
```
- **Streamlit Dashboard:** `http://localhost:8501`
- **FastAPI Server:** `http://localhost:8000`

### Option 2: Local Python Environment
1. Install dependencies:
```bash
pip install -r requirements.txt
```
2. Start the Production Webhook Server:
```bash
python main.py
```
3. Start the Evaluation UI:
```bash
python -m streamlit run eval_ui.py
```

### 🧪 Test the Live Webhook Security
While the FastAPI server is running, you can simulate a secure Razorpay webhook using our test script (which dynamically generates the required HMAC SHA256 signature):
```bash
python test_live_webhook.py
```
